# 전초선

HTML/JavaScript Canvas 2D 기반 탑다운 전술 슈터 시제품. 외부 에셋과 npm 런타임 의존성 없이 실행합니다. 사실적 시뮬레이터가 아니라 전장 분위기와 엄폐 중심 전투를 시험하는 버전입니다.

## 실행 및 조작
Node.js 설치 후 START.bat 또는 npm start. http://127.0.0.1:4187/ 접속. WASD 이동, 마우스 조준/사격, R 장전, Esc 일시정지. 대시와 강화 선택은 없습니다. 12발 탄창, 1.6초 장전, 빈 탄창 자동 장전입니다.

우측 상단 톱니바퀴에서 내 탄환 예상 경로, 적 탄환 예상 경로, 효과음을 각각 설정합니다. 경로 두 옵션은 기본 OFF이며 브라우저에 저장됩니다. 설정을 여는 동안 시뮬레이션이 멈춥니다. 예상선은 현재 방향의 궤적이며 적의 미래 이동까지 예측하지 않습니다.

## 전투
고정 배치 사수가 각 6명 있는 3개 구역. 적 사수는 0.45초 조준 후 3발 점사하고, 발사 속도는 1050px/s, 탄 피해는 22입니다. 각 적은 지정된 엄폐 지점에서만 대기, 모서리 노출, 점사, 복귀를 반복하며 플레이어를 추격하지 않습니다. 피격 시 엄폐로 복귀하고 측면을 잡히면 해당 지점에서 대응합니다. 모래주머니와 콘크리트는 탄과 시야를 막습니다. 철판을 포함한 모든 벽에서 탄은 소멸합니다. 도탄은 없습니다. 맵 외곽은 탄을 흡수합니다. 엄폐물 양 끝은 이동 가능한 경로로 연결됩니다.

적을 모두 처리하면 오른쪽 철문 표시등이 켜지고 출구로 이동할 수 있습니다. 다음 구역에서는 체력 15와 탄창을 보충합니다. 전투 화면은 하단 체력 막대와 탄약, 우측 상단 두 버튼만 남겼습니다. 상단 제목/구역/평가 문구는 표시하지 않습니다.

## 코드 구조
- config.js: 전투 수치
- stages.js: 고정 적/엄폐물/출구 배치
- arena.js: 벽 충돌, 탄 차단, 시야, 우회 경로
- enemy-fire.js: 조준과 점사 상태
- settings.js: 독립 옵션과 저장
- world.js: 전투 및 스테이지 진행
- weapon.js / knockback.js: 장전과 넉백
- renderer.js / effects.js / audio.js: 절차적 전장 배경, 병사, 효과음
- ui.js / input.js / main.js: 설정 UI, 입력과 고정 시간 시뮬레이션

npm test: 테스트 41개 통과. 엄폐에 의한 점사 중단, 탄 차단, 이동 경로, 설정 독립 저장, 장전, 넉백, 구역 진행 검증. 브라우저에서 설정 스위치와 전투 화면 확인. 난이도 체감은 추가 플레이테스트가 필요합니다. Steam 패키징, 패드 지원, 저사양 장시간 검증은 아직 포함하지 않습니다.

## 엄폐물 기반 시야

visibility.js가 플레이어 위치에서 엄폐물 모서리로 광선을 계산합니다. 조준 방향 기준 약 169도 전방만 보이며, 엄폐물 뒤의 적·탄·시각 효과는 숨깁니다. 뒤쪽과 가려진 지형은 아주 어둡게 남으며 적과 탄은 표시하지 않습니다. 적 예상선도 보이는 적에 대해서만 표시합니다. 이동하면 가려지는 영역이 실시간으로 달라집니다. 시야 관련 검증을 포함해 테스트 41개 통과, 브라우저 가려짐 화면 확인 완료.

## 소총수 표현

soldier.js가 헬멧, 방탄조끼, 양팔, 소총, 다리와 군화를 그립니다. 실제 이동 거리에 따라 보행 주기가 진행하고, 정지하면 발도 멈춥니다. 플레이어와 적 모두 같은 보병 렌더러를 사용합니다. 반사 로직과 반사 설정은 제거했으며 예상 경로도 첫 벽에서 끝납니다.

## 보행·피격 수정

하체는 실제 이동 방향으로 걷고 상체는 조준 방향을 유지합니다. 보폭과 걸음 속도를 줄였습니다. 피격은 작은 혈흔과 먼지, 사망은 쓰러진 병사로 표시하며 폭발 링과 파편 분출을 제거했습니다. 넉백도 줄였습니다. 플레이어 탄속 1550px/s, 적 탄속 1050px/s, 발사 간격 0.16초입니다. 적 탄속을 높여 사격 후 회피보다 사전에 엄폐하는 선택의 비중을 높였습니다.

cover-ai.js가 엄폐 수비 상태를 관리합니다. 후방 시야 제한은 유지합니다. 시야는 약 169도 전방이며 벽 뒤와 후방의 적 및 탄을 숨깁니다. 테스트 41개 통과.

엄폐물은 시야 마스크 이후 별도로 그려 항상 형태와 재질이 보입니다. 엄폐물 뒤의 공간/적/탄 및 후방 시야 차단은 그대로 유지합니다.


엄폐물 표면을 그릴 때 자기 자신만 시야 차단 계산에서 제외합니다. 다른 엄폐물이 가리거나 후방 시야 밖이면 해당 표면도 숨깁니다. 따라서 앞의 벽은 보이고 그 뒤의 적·탄·다른 벽은 보이지 않습니다.


피격 혈흔/먼지 크기와 명중 표시 시간을 늘렸습니다. 시야 마스크는 즉시 끊기지 않고 약 0.4초에 걸쳐 어두워집니다. sight-memory.js는 마지막으로 보인 적의 자세/위치만 저장하여 최대 0.45초 동안 흐릿하게 사라지게 합니다. 숨은 적의 현재 움직임은 추적 표시하지 않습니다. 테스트 43개 통과 및 브라우저 오류 없음 확인.


## 제압 사격과 편안한 화면

contact-memory.js는 마지막으로 목격한 위치와 이동 방향을 최대 4.5초 기억합니다. 적은 엄폐물 모서리에서 해당 위치에 점사하며, 숨은 플레이어의 현재 좌표를 추적하지 않습니다. 기억이 만료되면 사격을 중단하고 관측을 기다립니다. 탄은 모든 엄폐물에 막힙니다.

적 총성과 착탄음에 거리 감쇠와 좌우 패닝을 적용했습니다. 낮은 바람/저음 배경음을 추가하고 음량 피크를 압축합니다. 효과음과 배경음은 설정에서 끌 수 있습니다. 화면 흔들림 기본 OFF, 켜도 약한 진동만 적용합니다. 반복 피격 깜박임을 없애고 시야 잔상은 0.25초, 안개 전환 지연도 줄였습니다. 테스트 48개 통과, 설정 UI와 브라우저 오류 없음 확인. 실제 청감과 어지러움 개선 여부는 사용자 플레이 확인이 필요합니다.


## 사격 경로와 발소리

suppression-target.js가 마지막 접촉 위치 근처의 적 엄폐물을 찾고 양 끝의 통로를 교대로 겨냥합니다. 매 탄환에 퍼짐까지 반영해 자신의 엄폐물 또는 너무 가까운 장애물에 막히는 발사를 거릅니다. 숨은 플레이어의 실시간 위치는 참조하지 않습니다. footsteps.js는 실제 이동 거리마다 발소리를 재생하고, 정지/넉백 이동에는 발소리를 내지 않습니다. 가까운 적 발소리는 거리 감쇠와 좌우 패닝을 적용합니다. 테스트 51개 통과.


## 병사 역할

각 구역은 돌격병 3명과 엄호병 3명으로 구성됩니다. 돌격병은 목격하거나 총성을 들은 위치로 접근하고 사거리에서 멈춰 점사합니다. 엄호병은 지정된 엄폐물을 지키면서 모서리로 나와 점사·제압 사격한 뒤 복귀합니다. 같은 역할은 같은 AI 규칙을 사용하고, 두 역할의 군인 외형과 색상은 동일합니다. 역할 및 기존 동작 테스트 총 54개 통과.


## 사격 숙련도

역할과 별개로 신병·일반병·숙련병을 각 역할에 한 명씩 배치합니다. 조준 시간은 각각 0.55/0.30/0.17초이며 탄 퍼짐과 점사 사이 대기 시간도 다릅니다. 일반병과 숙련병은 조준 중 보이는 표적을 따라가고, 탄 비행시간에 따른 이동 예측을 적용합니다. 점사 시작 이후 방향은 고정됩니다. 외형·체력은 동일하며 숨은 위치를 실시간 추적하지 않습니다. 검증: 전체 테스트 57개 통과.


## 소총 발사음

gunshot-audio.js에서 날카로운 파열음, 중저역 발사음, 저음 충격과 짧은 반사음을 합성합니다. 적 총성은 거리 감쇠·좌우 방향을 유지하며 먼 총성은 고역을 줄이고 잔향을 늘립니다. 각 발사음의 마지막 잔향이 끝난 뒤 모든 임시 노드를 해제합니다. 출력 압축과 음소거 설정을 유지합니다. 전투 수치는 이번 변경에서 유지했습니다. 테스트 58개 통과; 실제 청감은 자동 테스트 대상이 아닙니다.


## 실제 녹음 총성으로 교체

기존 합성 총성은 제거했습니다. Free Firearm Sound Library(CC0)의 AR-15/D_32P.wav 및 AK-47/C_28P.wav 첫 단발음을 각각 플레이어와 적 총성으로 사용합니다. 1.35초 모노 PCM 파일 두 개를 게임에 포함하며 거리 감쇠, 좌우 방향, 약한 원거리 고역 감쇠만 적용합니다. 출처는 assets/audio/CREDITS.md에 있습니다. 테스트 60개 통과 및 브라우저 시작 후 오류 로그 없음 확인. 실제 청감 평가는 자동 검증에 포함되지 않습니다.


## 여섯 작전 지형

매복 현장(파괴 차량·탄흔), 외곽 검문소(초소·도로 차단물), 보급 기지(컨테이너·적재 상자), 통신 초소(안테나 기지·발전기·우회로), 부대 주둔지(막사·중정), 지휘소(벙커·콘크리트 방어선) 순서로 진행합니다. stages.js의 배치가 충돌·시야·길찾기에 공통으로 사용되고 terrain.js는 배경을 스테이지 전환 때만 그립니다. 건물은 진입 불가능한 엄폐물이며 도로·케이블·바닥 표시는 충돌하지 않습니다. 각 구역에 돌격병 3명과 엄호병 3명을 유지했습니다. 현재 완료 조건은 적 제압 후 출구 이동이며 폭파·통신 차단 등 별도 임무는 아직 구현하지 않았습니다. tests/terrain-preview.html에서 전체 지형을 비교할 수 있습니다. 전체 62개 테스트 통과(6구역 진행, 출구 이동, 적 진입/엄폐 동선 포함), 브라우저 지형 렌더링과 시작 확인.


## 적 부위별 부상

적에게 실제 명중한 탄마다 injury.js에서 머리 10%, 몸통 50%, 팔 20%, 다리 20%를 추첨합니다. 적 체력 100, 기본 소총 피해는 몸통 40/팔 18/다리 24이며 머리는 즉사입니다. 팔 부상은 영구 사격 불능(진행 중 점사 취소), 다리 부상은 영구 자력 이동 불능이며 넉백은 남습니다. 팔 부상자는 후퇴하고 다리 부상자는 제자리에서 반격합니다. 부상은 중첩되며 추가 피격으로 사망할 수 있습니다. 플레이어 피격 규칙은 기존 그대로입니다. 전체 67개 테스트 통과.


## 플레이 가능한 프롤로그와 이동 감속

작전 시작은 startPrologue()로 진입합니다. 동일한 아군 군복의 포로 3명, 마지막 대사, 세 번의 총성, 비무장 탈출, 오른쪽 아래 소총 확보, 응답 없는 무전 후 첫 전투로 이어집니다. 프롤로그는 기존 일시정지와 설정을 따르며 적 탄환은 벽에 막히고 실제 피해를 줍니다. 자동 테스트용 start()는 첫 전투로 직접 진입합니다. 일반 속도 180, 사격 중 117, 장전 중 99이며 장전 감속이 우선입니다. 실제 이동 속도가 적의 예측 조준에도 반영됩니다. 전체 85개 테스트 통과, 브라우저 비무장 프롤로그 장면과 오류 없음 확인.


프롤로그 재연출: 시작 9초는 차량과 잔해 뒤 은신 상태를 보여주는 전체 장면으로 진행합니다. 집행 병사들이 포로 정면으로 접근하고 장교의 준비·조준 명령 후 0.9초 간격으로 사격합니다. 동료는 손을 뒤로 모은 채 적 반대 방향으로 제자리에서 쓰러집니다. 주인공 위치는 엄폐물로 모든 집행 병사의 시야에서 차단됩니다. 수색 명령 후 이동 조작과 기존 시야 제한이 복귀합니다. tests/prologue-preview.html에서 네 시점의 실제 렌더링을 비교할 수 있습니다.
